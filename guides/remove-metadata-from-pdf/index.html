How to remove metadata and hidden data from a PDF

Look at the document’s properties for author, title and subject; then at comments, bookmarks, form fields and attachments; then search for text that isn’t visible on the page. The reliable way to remove all of it is to rebuild the file from what the pages show, instead of editing fields inside the old file.

Why editing the fields may not remove them

A PDF can be changed by adding to the end of the file, leaving the old content where it was. ExifTool, a widely used metadata tool, warns about this in its own documentation: its PDF edits are reversible, and the old information is never actually deleted. A viewer shows the new, empty author field; the old one is still in the file for anyone who looks.

How to clean a PDF

  1. Decide what must stay. Comments and form answers are sometimes the point of the document.
  2. Redact what is on the page first, with a tool that removes the text under the box.
  3. Export a rebuilt copy, rather than saving over the original.
  4. Check the copy: properties, comments, bookmarks, search, and copy-paste.
  5. Give the file a new name. The old file name can be the leak.

In PDF Redact

Exporting rebuilds each page from what you can see. Author, title, subject and keyword fields are blank, comment annotations are removed (a text box that shows on the page stays as part of the page), hidden text is not carried over, and bookmarks that mention something you redacted are removed. Before you get the file, the app checks the result:

  • Redacted text removed — no searchable text sits under any redaction box.
  • No missed copies — nothing you redacted still appears unredacted somewhere else in the file.
  • Original text removed — pages are rebuilt from what is visible, so only unredacted words remain searchable.
  • Searchable text visible — the text you kept is still searchable.
  • Metadata stripped — no author, creator or title metadata.
  • No annotations and bookmarks clean — comments, hidden annotations and outline entries are gone.

It is a redaction tool that cleans as it goes, not a metadata editor: on the Mac, for example, Export works once something is redacted.

Questions

Does printing to PDF remove metadata?
It removes some and may add its own, such as your user name as the author. Check the new file’s properties.
Does a password remove hidden data?
No. It controls who opens the file; everything inside is still there for whoever has the password.
Is the file name metadata?
It isn’t inside the PDF, but it travels with it and often names a person or an account.
