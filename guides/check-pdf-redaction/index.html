How to check that a PDF is really redacted

A PDF is properly redacted only if the hidden text is gone from the file, not just covered. Test it: search the PDF for a redacted word, select all and paste into a text editor, check the document’s properties for an author or title, and look for the same number elsewhere in the file. If any test shows the hidden information, the redaction failed.

The four tests

  1. Search. Open the redacted PDF and search for a word or number you hid. Any match means the text is still there.
  2. Copy and paste. Select all the text on a redacted page, copy it, and paste it into Notes or a text editor. Redacted text should not appear.
  3. Properties. Check the document’s metadata (on Mac: Preview → Tools → Show Inspector). Author, title and subject fields can leak names.
  4. Hidden copies. Look for the same information in headers, footers, form fields, comments, bookmarks and attachments.

Questions

Why do black boxes fail?
A box drawn with an annotation or markup tool is a separate layer. The original text stays in the file and can be copied, searched or revealed by deleting the box.
Is printing to PDF enough?
Not reliably. Some print paths flatten the page into an image, others keep the text layer. Test the result.
